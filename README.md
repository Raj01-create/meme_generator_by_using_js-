🎭 Meme Generator
A simple and fun Meme Generator built using JavaScript, where memes are fetched dynamically using the Fetch API, handled with Promises, and displayed instantly on the webpage.

This project helped me practice:

  JavaScript asynchronous concepts
  Fetching API data
  Promise handling
  DOM manipulation
  Event handling

🚀 Features

Fetch random memes from an API
Generate new memes with one click
Fast and responsive UI
Beginner-friendly project structure
Uses modern JavaScript concepts

🛠️ Technologies Used

HTML
CSS
JavaScript
Fetch API
Promises

📚 Concepts Practiced
🔹 Fetch API
Used to request meme data from an external API.
🔹 Promises
Handled asynchronous operations smoothly using .then() and .catch().
🔹 Callback Functions
Used functions as arguments for better code organization and event handling.
